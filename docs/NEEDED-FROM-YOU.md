# 首次接入需要的信息

可以直接在聊天里按公司填写，也可以发一个表格。不要提供账号密码、验证码或 token。

| 公司 | 产品/服务 | 目标客户与国家 | 中文/英文/其他 | 现有主页/网站 | 四个平台账号链接 |
|---|---|---|---|---|---|
| 公司 1 | | | | | |
| 公司 2 | | | | | |

每家公司请附：

- 已有的灵感素材库和关键词库，或其文件/文件夹链接。
- 至少 5 份你有权使用的产品照片、产品视频或品牌资料；没有也请注明。
- 3–10 条可以对外使用的真实卖点/事实，明确暂时不能承诺的效果。
- 想让潜在客户做什么：预约、购买、填表、发邮件、访问网站或私信。

没指定时先使用 Copenhagen 时区、每日 1 条母版视频、09:00 制作、18:00 分发；这些只是初始设置，尚未启动真实营销。

稍后的账号接入需要你亲自在平台页面完成登录/扫码/授权。公司信息和素材给齐后，先跑一家公司，验证内容和账号映射，再复制到其他公司。
